### About Me
Hi! I'm an endurance athlete and cat dad who works for GitHub in my free time. 

Along with that comes a love of coffee, carbs in all their forms, and data!  

Professionally I love problem solving, building things, and helping people achieve their goals. 

I got my start modernizing CI/CD pipelines, progressed to an infrastructure engineer building Openshift and Kubernetes cluters. Now at GitHub I help regulated industry enterprises adopt the platform at scale.  

I spend a lot of my time now working on GitHub Copilot. I work with engineering leaders and teams to scale responsible and effective use of Copilot. I've built tools like the [copilot-enabler](https://github.com/petercort/copilot-enabler) and have a small [blog](https://petercort.github.io/petercort/) where I post (usually in a silly way) about some cool things that I'm seeing and their use cases.
