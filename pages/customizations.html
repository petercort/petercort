    About

    Each leaf is a customization file. Colored dots indicate how Copilot loads the file. Folders show 📁; user-scope shows 👤; org-scope shows 🏢. Use the toggles to filter Claude-format paths, Copilot CLI files, and per-IDE personal instruction folders. Workspace files (.github/copilot-instructions.md, .github/prompts/, AGENTS.md) are IDE-agnostic — VS Code, JetBrains, Visual Studio, Eclipse and Xcode all read them. Sources: VS Code docs (custom-instructions, prompt-files, custom-agents, agent-skills, mcp-servers), GitHub Copilot CLI docs (cli-config-dir-reference, add-custom-instructions), and GitHub docs (configure-custom-instructions-in-your-ide).
